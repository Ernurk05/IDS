# ids project
IDS Project (Интрузияны анықтау жүйесі)
Сипаттамасы

Бұл жоба желілік трафик деректерін талдап, зиянды немесе қалыптан тыс әрекеттерді анықтауға арналған интрузияны анықтау жүйесін (IDS) білдіреді.

Жобаның негізгі мақсаты — машиналық оқыту және ережеге негізделген тәсілдер арқылы шабуылдар мен аномалияларды анықтау негізінде желі қауіпсіздігін арттыру.

Мүмкіндіктері
Желілік трафик деректер жиынтығын (CIC-IDS-2017) талдау
Зиянды және қалыпты трафикті анықтау
Бірнеше әдіс арқылы жіктеу:
Deep Neural Network (DNN)
Random Forest (RF)
Ережеге негізделген SIDS әдісі
Модельдердің нәтижелерін салыстыру

Қолданылған технологиялар
Python
Pandas, NumPy
Scikit-learn
TensorFlow / Keras
Matplotlib, Seaborn
Модельдер
Терең нейрондық желі (DNN)
Random Forest классификаторы
Қолтаңбаға негізделген IDS (SIDS)
Деректер жиынтығы

CIC-IDS-2017 (тазартылған нұсқасы)

Нәтижелер
Модельдер келесі көрсеткіштер бойынша бағаланды:

Accuracy
F1-score
Precision / Recall
ROC-AUC
Орындалу уақыты
Мақсаты.Бұл жоба дәстүрлі ережеге негізделген IDS пен машиналық оқытуға негізделген IDS жүйелерін салыстыруды көрсетуге бағытталған.
